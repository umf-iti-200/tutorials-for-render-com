Creating a Postgres Database

Steps

Step 1: Click on New -> Postgres

Step 2: Give a name for your database. I just added the app name + "-db" at the end

Step 3: You don't need to set the username, password and database. The platform will generate them automatically

Step 4: Make sure you selected the "Free" tier.

Step 5: Make sure you are not paying anything then click on "Create Database"

Step 6: As you can see, because you are using the free version, your database will expire in ~1 month

Step 7: Wait the database to be created

Step 8: Congratulations! you have created your first database on render.com. Now you can access the information generated by them. This information will be useful when you create your first web service.
